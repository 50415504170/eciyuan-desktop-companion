# 全屏陪玩 · Eciyuan Desktop Companion

Windows 单文件工具，让鹅次元通过原有陪玩链路接收一个显示器上的画面：单机游戏、浏览器、视频窗口和桌面。无需 OBS。

**实验版，仅支持经过校验的鹅次元 `0.1.15.624`（Windows x64）。** 不支持的安装包会被拒绝，不猜测其他版本的补丁地址。非腾讯官方产品，与鹅次元运营方无隶属关系。

## 下载和使用

从本仓库 [Releases](../../releases) 下载 `EciyuanDesktopCompanion.exe`，或下载含说明与校验值的 ZIP。

1. 启动工具，选择鹅次元安装目录中的 `Eciyuan.exe`。
2. 点击“检测兼容性”。此操作只校验文件，不结束当前通话。
3. 点击“开启陪玩”，允许 Windows 的管理员提示。**首次安装或更新补丁会重启鹅次元，断开当前通话。**
4. 保持“全屏陪玩 · 正在共享”小窗口可见。它可以被其他窗口遮住；采集的是该窗口在启动采集时所在的整个显示器。
5. 切到游戏或浏览器，与鹅次元照常对话。界面可能仍显示“无畏契约”，实际画面源已改为显示器。

展开“高级操作”后，点击“暂停画面共享”，或关闭共享小窗口，会隐藏该窗口，让采集器停止取帧。入口进程继续运行，工具不会主动结束语音通话。再次点击开启，如果补丁已安装且鹅次元正在运行，会恢复共享窗口，不重启鹅次元。

“高级操作”中的“还原原版”会恢复原版 `zlib1.dll` 并重启鹅次元，断开当前通话。原版备份 `zlib1_real.dll` 保留。本工具不修改游戏名单、不添加开机启动、不修改 Windows 全局音频或隐私设置。

界面采用紧凑深色玻璃质感，主按钮提供轻微回弹，遵循 Windows 动画开关。它使用系统自带 GDI+ 绘制，无需安装网页运行时；玻璃效果为渲染材质，不包含桌面背景实时折射。设计规范见 `DESIGN.md`。

## 边界和隐私

- 整屏中的聊天、通知、浏览记录和密码框都可能进入鹅次元的云端。敏感操作前先停止共享。
- 工具只改变画面来源；模型能否正确描述、响应速度、语音功能、付费资格及用量由鹅次元决定。它不提供独立 AI 服务。
- 原应用会缩放、抽帧。当前观察到的事件视频配置为 `1280x720@1fps`，不能保证连续视频或快速动作理解；视频声音没有单独接通或保证。受保护的视频内容可能黑屏。
- 一次共享一个显示器，不拼接多屏。切换显示器需要停止、移动共享小窗口，再重新开启，并以实际画面为准。
- 仅在鹅次元进程内修改采集调用，不注入游戏。入口辅助程序名为 `Valorant.exe`，只是复用原客户端进程检测。玩真实无畏契约前请还原原版采集；未验证反作弊兼容性，不作安全保证。
- 为缓解本机出现过的音频输出失败、通话自动结束和界面卡顿，启动时为鹅次元进程设置 `QT_MEDIA_BACKEND=windows`。这是进程内环境设置，不是音频驱动修复，不保证其他机器也稳定。
- 没有遥测、账号读取、调试命令通道或截图导出。唯一的网络活动由原鹅次元客户端进行。
- EXE 未进行商业代码签名。请核对 Release 中的 SHA-256；不支持的版本请等待适配，不要强行跳过版本校验。

## 原理

`zlib1.dll` 代理把 86 个 zlib 导出转发给用户本机的原版 `zlib1_real.dll`。在特定版本的鹅次元启动后，校验两个原始指令序列，再将窗口发现函数改为共享入口，并将 WGC `CreateForWindow` 调用点改为 `CreateForMonitor`。抓帧、编码、上传及 AI 回复仍由原客户端完成。

暂停时入口进程不退出，共享窗口不可见，窗口发现函数返回空 HWND，让原采集器停止。这样避免工具自身通过“游戏进程退出”事件主动结束陪玩。

发布包不包含鹅次元 EXE、原版商业 DLL、账号资料、聊天记录、运行日志或测试截图。

## 构建与测试

需要 Windows、PowerShell 5.1+、64 位 MinGW-w64 的 `g++.exe` / `gcc.exe` / `windres.exe`。本次使用本机已有的 MinGW 4.9.2 工具链。无需安装 Python 或 OBS 来使用成品；Python 3 只用于运行测试。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -CompilerDirectory 'C:\path\to\mingw64\bin'
python .\tests\smoke_test.py
python .\tests\smoke_test.py --eciyuan 'C:\path\to\Eciyuan.exe'
```

输出 `dist\EciyuanDesktopCompanion.exe`。管理脚本、采集代理和入口程序内嵌于 EXE。管理员操作由 EXE 自身提权后释放到 `Program Files\EciyuanDesktopCompanion\0.1.0`，检测操作使用当前用户的本地数据目录；不从用户临时目录执行提权脚本。

测试覆盖：内嵌资源、拒绝不兼容版本、拒绝前不改原文件、入口暂停/恢复和暂停时保持进程运行。测试不安装到运行中的鹅次元，不挂断现有通话。底层旧原型在本机验证过真实桌面帧与多轮上传；本次 GUI 封装仍标记为实验版，未完成跨电脑、长时间运行或全部音视频场景测试。
